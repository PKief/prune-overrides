Small CLI. Safer dependencies.

Keep only the overrides you need.

Find npm overrides that no longer change your dependencies. Scan first. Remove them when it’s safe.

Get started

Run inside your project, next to package.json and package-lock.json.

# Scan without changing project files
npx prune-overrides

# Remove safely redundant overrides
npx prune-overrides --fix

Prefer a global install? Run npm install -g prune-overrides, then use prune-overrides.

Scan

Checks every override in temporary workspaces. Shows results without changing project files or writing a project cache.

Fix

Rechecks the removal set, updates your package and lockfile, and rolls back if lockfile generation fails.

Check the whole tree

Checks all versions of the target package, including nested dependencies. Older versions mean the override stays.

Only four commands

prune-overrides
Scan and show results.
prune-overrides --fix
Remove safely redundant overrides.
prune-overrides --help
Show help.
prune-overrides --version
Show the installed version.

Read the results

  • Redundant: safe to remove under the dependency checks.
  • Required: removing it introduces older versions or a dependency conflict.
  • Unknown: the check could not finish safely. The override stays.

Exit codes: 0 means no redundant overrides remain; 1 means a scan found some; 2 means an error.

Before you run

Use Node.js 22.15+ and npm, with a version 2 or newer lockfile. Results apply to your current OS, architecture, and npm version.

This checks dependency resolution, not security advisories. Local and workspace dependencies may be reported as unknown. Yarn and pnpm are not supported.
